# 🏦 Sistema de Gestión de Caja de Ahorros

## Descripción

Aplicación web desarrollada para gestionar una caja de ahorros, permitiendo registrar socios, administrar saldos y controlar movimientos financieros mediante depósitos y retiros.

El sistema está compuesto por un backend desarrollado con FastAPI y un frontend desarrollado con React, comunicándose mediante servicios REST.

- Git

---

# Funcionalidades principales

## Gestión de socios

- Registrar nuevos socios.
- Consultar socios registrados.
- Visualizar información del socio y saldo disponible.

## Gestión de transacciones

- Registrar depósitos.
- Registrar retiros.
- Actualizar automáticamente el saldo.

## Movimientos

- Consultar historial de transacciones realizadas.
